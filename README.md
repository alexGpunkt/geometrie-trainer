# Geometrie-Trainer

Eine interaktive, deutschsprachige Web-App zum Üben geometrischer Aufgaben.

## Für Schülerinnen und Schüler

Die Anwendung läuft direkt im Browser. Es ist keine Installation und keine Anmeldung erforderlich.

## Technischer Hinweis

Die App besteht aus einer einzelnen HTML-Datei und wird über GitHub Pages bereitgestellt. Für Schriftarten und die QR-Code-Funktion werden externe CDN-Ressourcen geladen; dafür ist eine Internetverbindung erforderlich.
